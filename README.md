# G-ELEC+ Website

This repository contains the G-ELEC+ marketing site — a Vite + React + TypeScript project using shadcn/ui and Tailwind CSS.

Quick start

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
```

Tech stack

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS

Deployment

Build the project and deploy the generated `dist` folder to the static host of your choice.

For configuration or build questions, open an issue or contact the project maintainer.
